## Manual Icon Creation Instructions

Since we need PNG files for the app icons, please follow these steps:

### Option 1: Online SVG to PNG Converter

1. Go to https://cloudconvert.com/svg-to-png or any similar service
2. Upload the `app_icon.svg` file from assets/images/
3. Set the width and height to 1024x1024 pixels
4. Download as `app_icon.png` and save to assets/images/
5. Repeat for `app_icon_foreground.svg` → `app_icon_foreground.png`

### Option 2: Use Inkscape (Free)

1. Download and install Inkscape (free vector graphics editor)
2. Open `app_icon.svg`
3. Go to File > Export PNG Image
4. Set width and height to 1024 pixels
5. Save as `app_icon.png`
6. Repeat for the foreground image

### Option 3: Use a Design Tool

- Canva, Figma, or Adobe Illustrator
- Create a 1024x1024 canvas
- Draw or import a shopping bag icon
- Export as PNG

### What the Icons Should Look Like:

- **app_icon.png**: White shopping bag on blue (#2196F3) circular background
- **app_icon_foreground.png**: Blue (#2196F3) shopping bag on transparent background

### Alternative: Use Material Icons

If you prefer to use the exact Material Design shopping bag icon:

1. Go to https://fonts.google.com/icons
2. Search for "shopping bag"
3. Download the icon
4. Create your app icons using this as reference

Once you have created the PNG files, place them in the assets/images/ folder and we can proceed with generating the app icons for all platforms.
