3) CORE WORKFLOWS
==================================================

A) SHOP ORDER FLOW
Customer checkout -> shop-orders/{id} pending -> admin/merchant confirm -> preparing -> rider on_way -> delivered -> my orders past

B) CUSTOM ORDER FLOW
Customer 3-step form -> custom-orders/{id} pending -> admin/merchant/rider handling -> delivered/cancelled

C) MERCHANT FLOW
Assigned shop select -> new order alerts -> status updates -> product/deals management (permission-based)

D) RIDER FLOW
New actionable orders alert -> pickup -> live location updates -> delivered

E) ADMIN KHATA FLOW
Delivered orders aggregate -> commission + delivery revenue -> shop payouts -> expenses + owner drawings
